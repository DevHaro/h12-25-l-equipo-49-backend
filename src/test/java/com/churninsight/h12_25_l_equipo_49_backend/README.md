# h12-25-l-equipo-49-backend

Backend API REST para predicción de churn.

## Descripción
Este proyecto corresponde al backend del sistema de predicción de churn,
desarrollado con Spring Boot y Java 17.

## Tecnologías
- Java 17
- Spring Boot
- Gradle
- Spring Web
- Lombok
- Validation

## Requisitos
- Java 17
- Gradle (incluido con wrapper)

## Ejecución del proyecto
Desde la raíz del proyecto ejecutar:

```bash
./gradlew bootRun


Una vez ejecutado el proyecto, la API estará disponible en:

http://localhost:8080

(Disponible solo mientras la aplicación esté en ejecución)
